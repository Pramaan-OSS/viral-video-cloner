# Sourcing a video from a link

Read this when a reference or source clip lives on a video page. A local file the author supplies
always works: drop it into the project and continue. Fetching a video by its public address goes
through Pramaan's media download, which needs platform file storage that is not live yet: when the
work needs the media now, say so plainly and ask the author to supply the file. Source details and
spoken words for a pasted short-video link (caption, counts, duration, transcript) already work
through Pramaan.

A website's interface — scrolling or interaction — belongs to [browser
automation](../environment/local-tools.md), not to media sourcing.
